# Картинки

Положите сюда файл с таким именем — он сразу появится на поле, код менять не нужно.

| Файл | Где виден |
|------|-----------|
| `board-center.png` | центр круга |
| `corner-tl.png` | левый верхний угол поля |
| `corner-tr.png` | правый верхний угол |
| `corner-bl.png` | левый нижний угол |
| `corner-br.png` | правый нижний угол |

Если файла нет, место остаётся пустой рамкой.
