# Выход из круга

Настольная игра о деньгах для браузера (iPad, компьютер, телефон). Версия 1: внутренний круг, 1–10 игроков на одном устройстве.

Открыть: https://zab-simon.github.io/abbtl/261114/

## Как устроено (коротко)

```
261114/
├── index.html            страница
├── src/
│   ├── data/             ВСЕ цифры игры — менять только здесь
│   │   ├── professions.js   12 профессий
│   │   ├── cards.js         колоды: маленькие/большие дела, рынок, траты
│   │   ├── board.js         24 клетки круга
│   │   └── rules.js         числа из правил (кредит 10%, 3 ребёнка, пропуски ходов…)
│   ├── core/             правила, без экрана и без сети
│   │   ├── engine.js        createGame / applyAction — единственное место, где меняется игра
│   │   ├── finance.js       расчёт бланка (итоги не хранятся — всегда считаются)
│   │   └── rng.js           случайности с «зерном» — партию можно повторить точь-в-точь
│   ├── net/
│   │   └── localGame.js     транспорт «одно устройство»; сюда же добавится сеть
│   ├── i18n/             языки: ru.js, en.js (базовый), cards.ru.js — тексты карточек
│   └── ui/               экран: поле, кубики, бланк, карточки, настройки, звук, сохранение
├── themes/               оформление: base.css (разметка), cartoon.css / strict.css (цвета)
├── assets/img/           место для своих картинок
├── tests/engine.test.mjs автопроверки правил
└── DECISIONS.md          решения по спорным местам материалов
```

### Главный принцип

Игра = состояние (обычный JSON) + действия. Экран ничего не меняет сам: он отправляет действие
(`{ type: 'ROLL', playerId }`), движок проверяет правила и возвращает новое состояние.

Поэтому:
- **ошибку легко найти**: «Журнал → Скачать журнал» сохраняет все действия; их можно прогнать заново и получить ту же ошибку;
- **ошибку легко исправить**: цифры — в `data/`, правила — в `core/engine.js`, тексты — в `i18n/`, вид — в `themes/`; они не зависят друг от друга;
- **сеть добавляется без переделки**: сервер вызывает тот же `applyAction` и рассылает состояние; на экране `LocalGame` меняется на `RemoteGame` с тем же интерфейсом (`getState / dispatch / subscribe`). Подходит и для домашней сети, и для интернета;
- **сохранение надёжное**: после каждого действия состояние пишется в браузер; если сохранение повреждено, игра просто предлагает начать заново.

### Проверки

```
cd 261114 && node --test tests/engine.test.mjs
```
Проверяется: итоги всех 12 профессий совпадают с карточками, поле, количество карточек, кредиты, погашение долгов,
покупка/продажа, акции и дробление, благотворительность, катер, банкротство, выход из круга, детерминированность,
длинная случайная партия на 10 игроков.
