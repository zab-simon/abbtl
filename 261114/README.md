# Выход из круга

Настольная игра о деньгах для браузера (iPad, компьютер, телефон). Версия 1: внутренний круг, 1–10 игроков на одном устройстве или до 4 игроков по сети (QR-код).

Открыть: https://zab-simon.github.io/abbtl/261114/

## Как устроено (коротко)

```

├── src/
│   ├── data/             ВСЕ цифры игры — менять только здесь

│   │   ├── cards.js         колоды: маленькие/большие дела, рынок, траты

│   │   └── rules.js         числа из правил (кредит 10%, 3 ребёнка, пропуски ходов…)
│   ├── core/             правила, без экрана и без сети
│   │   ├── engine.js        createGame / applyAction — единственное место, где меняется игра
│   │   ├── finance.js       расчёт бланка (итоги не хранятся — всегда считаются)
│   │   └── rng.js           случайности с «зерном» — партию можно повторить точь-в-точь

│   │   └── peer.js          подключение WebRTC (PeerJS)
```

### Главный принцип

Игра = состояние (обычный JSON) + действия. Экран ничего не меняет сам: он отправляет действие
(`{ type: 'ROLL', playerId }`), движок проверяет правила и возвращает новое состояние.

Поэтому:
- **ошибку легко найти**: «Журнал → Скачать журнал» сохраняет все действия; их можно прогнать заново и получить ту же ошибку;
- **ошибку легко исправить**: цифры — в `data/`, правила — в `core/engine.js`, тексты — в `i18n/`, вид — в `themes/`; они не зависят друг от друга;
- **сеть без переделки движка**: хост применяет действие и рассылает гостям только само действие (десятки байт);
  гости применяют его тем же движком, состояние у всех совпадает. Если сообщение потерялось — гость сам просит полную копию;
- **сохранение надёжное**: после каждого действия состояние пишется в браузер; если сохранение повреждено, игра просто предлагает начать заново.

### Проверки

```
cd 261114 && npm test
```
Проверяется: итоги всех 12 профессий совпадают с карточками, поле, количество карточек, кредиты, погашение долгов,
покупка/продажа, акции и дробление, благотворительность, катер, банкротство, выход из круга, детерминированность,
длинная случайная партия на 10 игроков; сетевой протокол (лобби до 4, синхронность, чужой игрок, переподключение, потеря сообщения).

## Игра по сети (до 4 игроков)

1. На одном устройстве: «Создать сетевую игру» — появится QR-код. Код постоянный для этого устройства, его можно распечатать.
2. Остальные сканируют его камерой (iPad, iPhone, компьютер), вводят имя и цвет, жмут «Подключиться».
3. Создатель жмёт «Начать игру». Каждый ходит за себя со своего устройства.

Повторное подключение — само: устройство помнит игру. Если связь пропала, гость переподключается и получает своё место.
Интернет нужен только на секунду при соединении (сервер «рукопожатия» PeerJS); ходы идут напрямую по локальной сети.
Задержка в домашнем Wi-Fi — единицы миллисекунд; в тесте обновление на втором устройстве приходило за ~40 мс.
