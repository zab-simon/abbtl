# Решения, которые я принял сам (проверь утром)

Правило было такое: ничего не придумывать. Ниже всё, где материалы молчат, противоречат сами себе
или содержат опечатку. Каждое решение — одна строка в коде, менять легко.

## Правила

| № | Что | Как сделал |
|---|-----|-----------|
| R1 | Порядок клеток внутреннего круга | Снят с присланных фото поля: Возможность, Давай потратимся, Возможность, Благотворительность, Возможность, Чек … (`src/data/board.js`) |
| R2 | Благотворительность: «право бросать 2 кубика» | Игрок выбирает 1 или 2 кубика в каждом из 3 ходов |
| R3 | Банкротство: что с чеком, на котором оно наступило | Этот чек не платится; клетка, куда шла фишка, не срабатывает; ход заканчивается; потом пропуск 3 ходов |
| R4 | Банкротство: акции | Продаются банку за половину уплаченного (как недвижимость — за половину первого взноса) |
| R5 | Объединение акций при нечётном количестве | Округление вниз |
| R6 | Когда можно брать/возвращать кредит и гасить долги | Любому игроку в любой момент. Нельзя: во время своего банкротства и при покупке карточки «8 квартир … без банковского кредита» |
| R7 | Выход из круга (второго круга в версии 1 нет) | В начале своего хода, если пассивный доход > общих расходов, игрок автоматически выходит и больше не ходит. Когда все вышли или выбыли — конец игры, список по порядку выхода |
| R8 | Кто ходит первым | Каждый «бросает кубик» автоматически, при равенстве — переброс |
| R9 | Аудитор («игрок справа») | Игрок, который ходит перед вами |
| R10 | Колода кончилась | Сброс перемешивается и становится новой колодой |
| R11 | Продажа на рынке дешевле ипотеки | Разницу игрок доплачивает сам |
| R12 | «Продайте возможность другому игроку» | Только на карточках покупки актива: вытянувший передаёт карточку за договорную цену |
| R13 | Акции «покупать можете только вы» | Покупает тот, у кого карточка; продать по цене карточки может любой владелец. Депозиты и 2BIG — покупает и продаёт любой |
| R14 | Формат денег | `$13.200` — как на русских карточках профессий |

## Оформление

- Название игры — «Выход из круга» (твоё). Тикеры акций (OK4U, ON2U, MYT4U, GRO4US, 2BIG, CD) оставил.
- Тексты карточек переписаны своими словами, цифры и смысл — как в оригинале (`src/i18n/cards.ru.js`).
- Бланк повторяет бумажный: те же разделы, строки и порядок.
- Картинки оригинала не использованы. Свои картинки кладутся в `assets/img/` (см. README там).
